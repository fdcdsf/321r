# 321r.ru — инфраструктура на 3 VPS

Отказоустойчивая система: Pangolin-кластер (доступ к сервисам), Docker Swarm (запуск
сервисов), AmneziaWG-меш (связь узлов), Postgres + Patroni (данные с автофейловером),
Remnawave (VPN для обхода цензуры), Komodo (панель управления).

- **[PLAN.md](PLAN.md)** — полный план (v11): роли узлов, фазы, сценарии отказов, порты.
- **[docs/dns.md](docs/dns.md)** — записи Cloudflare для зоны 321r.ru.

## Быстрый старт

1. Заполнить `<IP-A/B/C>` в [docs/dns.md](docs/dns.md) → создать записи в Cloudflare.
2. Чек-лист фазы 0 в [PLAN.md](PLAN.md).
3. Дальше — по фазам, не идя дальше, пока не зелёные проверки.

## Ключевые решения (чтобы не переоткрывать)

- Домен **321r.ru**, узлы **a/b/c** (a = РФ).
- DNS: один хаб **`dns.321r.ru`** (A ×3), всё остальное — **CNAME → dns**: при смене IP
  руками не правится ничего (ddns.sh обновляет 6 записей сама).
- Меш — **AmneziaWG** сразу; запасной путь — обычный WireGuard.
- Контрольные панели (Komodo, Remnawave) — на VPS; дом — только Newt и сервисы.
- Автовосстановление встроено там, где данные: Swarm (сервисы), Patroni (Postgres),
  реплика-сет (MongoDB). Ручное — только крайние случаи.
- Расширение: узлы **D и E** (год бесплатно от старого хостинга) принимаются без переделки
  (3 → 5 и обратно); минимум — 3 узла.
