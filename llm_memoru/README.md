# llm_memoru — память для ассистента

- **`MEMORY.md`** — единственная точка правды для новой сессии ассистента. Читать первым делом.
- **`3-vps.json`** — полный дамп диалога со старой моделью (`mimo-v2.6-flash-free`), ~20 МБ.
  В git **не идёт** (добавлен в `.gitignore`) — нужен только для локальной археологии.
  Если станет не нужен — можно удалить, всё важное из него выжато в `MEMORY.md` и историю git.

Правила ведения: после каждого заметного этапа обновлять `MEMORY.md` (§4 «Текущее состояние»
и §5 «Косяки»). Дампы диалогов класть сюда же, но не коммитить.
