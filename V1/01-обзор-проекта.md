# 01 — Обзор проекта

Обновлено: 2026-11-12. См. также: [02-архитектура](02-архитектура.md), [03-факты](03-факты.md).

## Задача

Отказоустойчивая система на нескольких VPS (минимум 3, «пока буквы алфавита не кончатся»),
которая:

1. **Переживает потерю любого одного сервера** — сервисы продолжают работать сами.
2. **Переживает блокировки РКН** — смену IP и протоколов лечит автоматика, не человек.
3. **Переживает смену IP по требованию провайдера** — правки руками не нужны.
4. **Восстанавливается полностью за ~1 час** из git + бэкапов (новый сервер вместо сгоревшего).
5. **Работает без присмотра до месяца** — человек нужен только для физической замены железа.
6. **Станет общедоступной** — реальные пользователи ставят её скриптами, поэтому каждый
   урок эксплуатации превращается в автоматику установщика.

## Ограничения (от них всё и пляшет)

- **Только бесплатное/открытое ПО.** Никаких платных сервисов.
- **Пользователь в РФ.** Cloudflare: только «серое облако» (обычный DNS); оранжевое облако и
  туннели Cloudflare в РФ заблокированы. Протокол WireGuard могут резать по DPI —
  транспорт меша сразу **AmneziaWG 3.1** (обфускация).
- **Из РФ — только на свои VPS, из VPS — куда угодно** (GitHub, Let's Encrypt, Cloudflare API).
- Секреты — никогда в чат и никогда в git.

## Принципы (кратко, с картиной мира)

1. **Всё находится по DNS-именам, не по IP.** IP — как почтовый индекс: сменился — почта
   всё равно найдёт адресата, потому что мы держим «справочник» (DNS) в актуальном виде.
2. **Слои независимы**: вход (Pangolin), вычисления (Swarm), состояние (БД), связь (меш) —
   падение одного не валит остальные.
3. **Ни одна копия данных не живёт в единственном экземпляре на ненадёжном ящике.**
4. **Восстановление, а не «дорогая HA»**: git + бэкапы + скрипты дешевле и понятнее
   отказоустойчивого зоопарка.
5. **РФ-нода — гарантированный вход**: её собственный IP блокировать нечем — через неё
   всегда можно попасть в систему из РФ.
6. **БД — «глупые исполнители», решения принимает Swarm.** Кто первичный — решает скрипт
   `db-guard` по голосам кластера, движки PG/Mongo лишь исполняют команду.
7. **Данные живут ровно там, где живёт приложение** (у приложения X — свой набор серверов
   S(X) и никаких чужих копий на чужих дисках).
8. **Узлы — профили, а не имена** (см. ниже).
9. Каждая фаза имеет **проверки** — дальше не идём, пока не зелёные.
10. Каждый фикс → **сразу в документацию и в автоматику установщика**.

## Философия: узлы — профили, а не имена

Конкретные сервера (их IP, железо, локации, имена a/b/c) — это **пример одного развёртывания**,
а не архитектура. Архитектура держится на ролях и формулах:

- меш адресуется по `nodes.map` (alias → mesh-IP → имя в Swarm);
- размещение БД — по списку узлов приложения S(X) из `apps.d/`;
- кворумы — формулы от числа узлов (⌊M/2⌋+1, правило менеджеров 2K+1);
- цепь назначения первичного — по порядку узлов S(X).

Поэтому кластер масштабируется свободно: 3 → 5 → 7 → N узлов и обратно, без переделки кода.
Процедуры: [05-добавление-ноды](05-добавление-ноды.md), [06-удаление-ноды](06-удаление-ноды.md).

## Аналогии для объяснений

| Термин | Аналогия |
|---|---|
| Кластер из N VPS | Дом из LEGO: детали можно менять, инструкция та же |
| Меш (AmneziaWG) | Личный лифт между этажами здания — мимо улицы (интернета) |
| Swarm-кворум | Сходка соседей: решения принимаются большинством голосов |
| db-guard | Старший по подъезду: следит, кто «главный», и назначает нового |
| VIP 10.66.0.99 | Постоянный телефонный номер: абоненты звонят по нему, а кто за него ответит — забота АТС |
| Фенсинг | Узел, потерявший связь с соседями, «запирается у себя», чтобы не портить общие данные |
| Pangolin | Вахтёр с табличками имён: по имени домена доводит до нужной двери |
| DNS-хаб | Справочник: меняется индекс одной строки — все адреса находятся |

## Что в итоге получает пользователь (продукт)

- Сайты/панели/сервисы на своих доменах (`*.321r.ru`) с настоящими сертификатами.
- Панель управления (Pangolin) и панель серверов (Komodo) — на своих доменах.
- VPN (Remnawave) для устройств — обход блокировок.
- Скрипты установки: чистая VPS → рабочий узел за минуты, кластер — за час.
- Документацию (эту вики) и дриллы, подтверждающие, что обещания — не сказки.
